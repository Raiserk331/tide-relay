# Tide Relay

A compact original browser logic game. Each step changes the tide; amber and blue gates must match the arriving tide. Still-water tiles preserve the tide on departure. Collect every pearl and reach the lighthouse.

12 levels, unlimited undo, restart, keyboard and pointer controls, shortest-route hints. No external libraries, remote assets, ads, analytics or network requests. System fonts and CSS shapes.
